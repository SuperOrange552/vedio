# 草腥味

一支约 46 秒的 1080p 短片，围绕这段话展开：

> 小时候贪玩，捻碎了几只蚂蚁，手上只剩淡淡的草腥味。
> 长大后各种考试、经济的压力袭来，时代的一粒尘埃落在普通人身上，就是滔天巨浪。
> 抬头看向天空，竟然又一次闻到那股熟悉的草腥味了。

**成片：[`output/草腥味.mp4`](output/草腥味.mp4)**

## 分镜

| 时间 | 画面 | 旁白 |
|---|---|---|
| 0–7s | 夏日午后，一队蚂蚁爬过泥地；一根手指从天而降按下去 | 小时候贪玩，捻碎了几只蚂蚁。 |
| 7–13s | 指尖特写，指纹上一点污痕，淡绿色的气味升起 | 手上，只剩下淡淡的草腥味。 |
| 13–16s | 日升日落，小孩长成大人，色彩褪成灰 | 后来，我长大了。 |
| 16–22s | 灰色城市，“考试 / 升学 / 房租 / 房贷 / KPI / 35岁…”砸落堆积，人慢慢弯下腰 | 考试、升学、房租、房贷……各种压力接踵而来。 |
| 22–25s | 黑暗中一粒发光的尘埃缓缓飘落 | 时代的一粒尘埃， |
| 25–32s | 尘埃落在一个小小的人身上，掀起遮天的巨浪，吞没一切 | 落在普通人身上，就是滔天巨浪。 |
| 32–37s | 蚂蚁视角：巨大的草叶，小人抬头望天 | 我抬起头，看向天空。 |
| 37–46s | 一根巨大的手指遮天而下，草腥味飘落 → 黑场，片名 | 竟然，又一次闻到了那股熟悉的草腥味。 |

结尾的反转：“我”成了当年那只蚂蚁。

## 制作方式

全部由代码生成，无外部素材：

- **配音**：[sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) + Kokoro v1.1-zh 离线中文 TTS（男声，`src/tts.py`），同时输出每句时间轴 `timeline.json`
- **画面**：Python + Pillow + NumPy 逐帧程序化绘制，2 倍超采样抗锯齿、暗角、胶片颗粒、字幕（`src/render.py`）
- **配乐/音效**：NumPy 合成钢琴分解和弦、Pad、虫鸣、风声、低频轰鸣与浪声，旁白处自动压低背景（`src/audio.py`）
- **合成**：ffmpeg（H.264 + AAC）

## 重新生成

```bash
pip install sherpa-onnx numpy pillow   # 另需 ffmpeg
./build.sh                             # 首次会从 GitHub 下载约 360MB 的 TTS 模型
```

修改 `src/script.py` 即可更换文案，画面时间轴会根据配音长度自动对齐。
